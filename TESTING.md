- валидация цены;
- валидация года выпуска;
- обязательность производителя;
- изменение автомобиля;
- обязательность автосалона и сотрудника при продаже;
- обязательность позиций продажи;
- обработка недостаточного остатка;
- успешное оформление продажи;
- загрузка каталога из SQLite;
- поиск автомобиля;
- уменьшение остатка после продажи;
- отказ при продаже сверх остатка.
